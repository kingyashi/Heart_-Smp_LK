HEART SMP WEBSITE
=================
Files: index.html, style.css, script.js

1) EDIT YOUR INFO
   Open script.js in Notepad. At the top, change:
     ip       -> your server IP
     discord  -> your Discord invite link
     version  -> your Minecraft version
     rules    -> add/remove/edit lines (keep the quotes and commas)

2) PUT IT ONLINE (free, GitHub Pages)
   a. Make an account at github.com and click New repository (name it e.g. heart-smp, set Public).
   b. Click "uploading an existing file", drag in index.html, style.css, script.js, then Commit.
   c. Go to Settings > Pages > Source: "Deploy from a branch", Branch: main, folder: / (root), Save.
   d. After ~1 minute your site is live at https://YOUR-USERNAME.github.io/heart-smp/

To test locally, just double-click index.html.
